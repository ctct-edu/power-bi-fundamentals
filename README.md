## Power BIによる業務データ分析入門 演習ガイド

## はじめに

本マニュアルはCTCテクノロジー主催「[Power BIによる業務データ分析入門](https://www.school.ctc-g.co.jp/course/P618.html)」のラボマニュアルになります。


## マニュアルの見かた

講師の指示に従い、「 **[LabManual](https://github.com/ctct-edu/power-bi-fundamentals/tree/main/LabManual)** 」のフォルダへ移動してください。

フォルダ内に各演習のラボマニュアルが掲載されています。

ラボマニュアルに従って演習を実施してください。

## 演習一覧

| 演習 | 内容 | 時間 | 主なデータソース |
|---|---|---:|---|
| [01](./LabManual/01-create-first-report-from-excel.md) | Excelから複数ビジュアルの簡易レポートを作成 | 25分 | Excel |
| [02](./LabManual/02-transform-data-with-power-query.md) | Power Queryでデータを整形 | 25分 | Excel |
| [03](./LabManual/03-data-modeling-and-dax.md) | 複数データのモデル化とDAX | 45分 | Excel、SQL Server、SharePoint |
| [04](./LabManual/04-report-visualization.md) | グラフ・表・マトリクスで可視化 | 45分 | 演習03のモデル |
| [05](./LabManual/05-sharing-with-power-bi-service.md) | Power BI Serviceで共有 | 25分 | Power BI Service |

## ファイルの配置

講師より配布される演習用仮想マシンには以下の構成で演習用ファイルが展開されています。

各演習にてExcelフォルダ内に格納されているファイルを使用します。その他のフォルダについてはサンプルデータや代替手段として使用するデータが含まれています。

```text
C:\PowerBITraining\
├─ Excel\
└─ Fallback\
└─ SharePoint\
└─ SQLServer\
```

> 本資料は2026年7月時点のPower BIを前提にしています。プレビュー機能は必須操作にしていません。

# SharePoint販売目標リスト 準備手順

講師または環境管理者が、演習03で使用するSharePoint Onlineリストを準備するための手順です。

## 使用ファイル

- [販売目標_リスト作成用.xlsx](販売目標_リスト作成用.xlsx)

## 作成されるデータ

| 項目 | 値 |
|---|---:|
| リスト名 | 販売目標 |
| 行数 | 576 |
| 対象期間 | 2025年7月～2026年6月 |
| 店舗 | 12 |
| 商品カテゴリ | 4 |

## 推奨列

| 列名 | SharePoint列型 | 必須 | 備考 |
|---|---|---|---|
| 目標ID | 1行テキスト | はい | `T00001`形式 |
| 年月 | 日付と時刻 | はい | 時刻は不要 |
| 店舗ID | 1行テキスト | はい | `S001`形式 |
| 商品カテゴリ | 1行テキスト | はい | 4カテゴリ |
| 販売目標金額 | 数値 | はい | 小数点以下0 |

既定の［タイトル］列が作成される場合は、`目標ID`へ名前変更するか、Excelの `目標ID` を別列として作成し、Power BIで不要なタイトル列を削除します。

## Excelからリストを作成する

1. 研修用SharePointサイトを開きます。
2. ［サイト コンテンツ］→［新規］→［リスト］を選択します。
3. ［Excelから］を選択します。
4. `販売目標_リスト作成用.xlsx` をアップロードします。
5. テーブルとして `SalesTargetImportTable` を選択します。
6. リスト名を `販売目標` とします。
7. 列名と列型を上表と照合します。
8. ［作成］を選択します。
9. 先頭、途中、末尾のレコードを確認します。
10. リストの項目数が576であることを確認します。

## Power BI接続用サイトURL

受講者へは、リスト個別URLではなくサイトURLを配布します。

```text
https://<tenant>.sharepoint.com/sites/<training-site>
```

次のようなリスト画面固有の部分は含めません。

```text
/Lists/販売目標/AllItems.aspx
```

## 権限

- 受講者にはリストの読み取り権限を付与します。
- リスト作成やデータ変更が不要な受講者へ編集権限を付与しません。
- 可能であれば個人ではなく研修用Microsoft Entraグループへ権限を付与します。
- 研修終了後に権限を削除する日を決めます。

## 接続確認

研修前にPower BI Desktopで確認します。

1. ［データを取得］→［SharePoint Onlineリスト］または［SharePointリスト］を選択します。
2. サイトURLを入力します。
3. 組織アカウントで接続します。
4. 実装方式を選べる場合は `2.0` を選択します。
5. ナビゲーターに `販売目標` が表示されることを確認します。
6. Power Queryで576行と5つの業務列を確認します。

## トラブルシューティング

### リストが表示されない

- サイトURLの範囲を確認します。
- アカウントにサイト閲覧権限があるか確認します。
- 別テナントのアカウントでサインインしていないか確認します。

### 列名に `field_1` などが表示される

SharePoint内部名と表示名の違いです。Power Queryで表示名を確認し、演習で指定したクエリ名・列名へ揃えます。

### 日付が時差でずれる

SharePoint Onlineリストコネクタの実装方式 `1.0` では、タイムゾーン変換により月初が前月末へずれる場合があります。単に［日付］型へ変更しても元の月には戻りません。

1. 接続時に実装方式 `2.0` を選択します。
2. Power Queryで `対象月` が2025年7月1日から2026年6月1日まで、すべて月初になっていることを確認します。
3. `2.0` を選択できない、または日付がずれる場合は、実装方式 `1.0` のまま補正せず、フォールバックのExcelを使用します。

## フォールバック

SharePointを利用できない場合は [販売目標.xlsx](../Fallback/販売目標.xlsx) を使用します。レコードと列名は同一です。

## 研修後

1. 研修用ワークスペースとSharePointサイトの利用期間を確認します。
2. 一時的に付与した受講者権限を削除します。
3. 再利用しない場合はリストを削除します。
4. 削除前に、ほかの研修や利用者が参照していないことを確認します。
